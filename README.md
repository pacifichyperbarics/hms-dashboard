# HMS Home v4 experiment

This branch is an isolated experiment based on HMS Clinic Dashboard v3.

- V3 remains the current production dashboard.
- Linear Healtho2 remains authoritative for project work.
- This prototype uses representative local data and makes no live writes.
- V4 tests the daily orientation screen, accountability view, app catalog, clinic portfolio, signals, and an HMS-specific chat surface.
- Live connectors, cross-channel event ingestion, authentication, and write actions are intentionally deferred until the experience is validated.
